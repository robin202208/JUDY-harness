# 代码审查规范

## 四维检查清单
- 正确性：分支与边界、空值/异常路径、状态一致、并发安全
- 安全：输入校验、注入与 XSS、鉴权、密钥不硬编码、依赖版本
- 性能：复杂度、循环内副作用、资源释放
- 可维护：命名清晰、函数单一职责、重复代码、测试覆盖关键路径

## 输出格式
每条意见按如下结构：

- [严重级: 阻塞/建议/可选] 文件:行号 — 问题描述
  为什么：...
  建议：...（附示例）

## 分级
- 阻塞：功能错误、安全漏洞、明显回归
- 建议：可改进但可后置
- 可选：风格、命名偏好
