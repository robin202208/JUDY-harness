# 数据分析规范

## 分析流程
1. 明确目标与口径（指标、范围、维度）→ 2. 取数与清洗 → 3. 探索性分析 → 4. 结论与报告

## 数据清洗清单
- 缺失值：计数并说明处理方式（删除/填充/标记）
- 异常值：用 IQR/标准差识别，标注而非盲目删除
- 类型：日期/数值/分类字段类型一致

## 常用分析
- 分布：直方图、分位数
- 趋势：时间序列、同比环比
- 对比：分组均值、差异（说明方法适用条件）
- 相关：相关系数（注明适用条件）

## 报告结构
背景与目标 → 数据与方法 → 主要发现 → 结论与建议 → 附录（口径与限制）
