# IP 打造 playbook

## 1. 定位（先定方向）
- 问清六件事：身份、目标人群、场景、痛点、差异证据、内容边界
- 输出一句话定位：人群 + 问题 + 差异 + 证据
- 人设三件套：身份标签、说话方式、固定视觉/场景
- 没有证据的差异不要写；不知道的先问

## 2. 选题（存量优先）
- 矩阵：人群 × 场景 × 痛点 × 形式（口播 / 剧情 / 图文）
- 每条选题必须能被正文兑现，不做纯标题党
- 优先从已有案例、客户问题、后台搜索词里找存量
- 一周 5 条能拍完，比 30 条拍不完更有用

## 3. 30 秒口播脚本
- 0–3 秒：钩子（反常识 / 痛点 / 代价）
- 3–12 秒：冲突（具体化问题，给反例）
- 12–24 秒：反转或方法（给可执行的一步）
- 24–30 秒：行动（关注 / 评论关键词 / 私信）
- 台词 ≤120 字，口语化，标注重音与停顿

## 4. 拍摄清单
- 每 5 秒一个镜头；标注景别、机位、道具、字幕关键词
- 优先手机可拍：自然光、固定机位、少转场

## 5. 发布与复盘
- 发布走排期提醒，不承诺平台一键发布
- 复盘字段：播放、完播、互动、涨粉、咨询/线索
- 结论只写一条：下周保留什么、停掉什么、放大什么
